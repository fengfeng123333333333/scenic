# 景区小程序首页优化方案 · 深圳马戏团

## 一、问题诊断（Before）

| # | 问题 | 现状（截图依据） | 影响 |
|---|------|------------------|------|
| 1 | **品牌识别 ≈ 0** | 米色背景 + 棕色通用图标，看不出"马戏团 / 演艺"任何属性 | 用户记不住你 |
| 2 | **AI Slop Test 必败** | 标准"卡片+圆角+通用阴影"组合，毫无个性 | 给同事看会被认成"AI 套壳" |
| 3 | **信息密度均匀** | 营业时间/地址/电话三行同等粗细，没有主次 | 关键信息被淹没 |
| 4 | **9 宫格 14 个入口堆一起** | 一屏内 4×4 网格全部同色同尺寸 | 用户找不到重点，转化率低 |
| 5 | **Banner 利用率极低** | 大幅家庭照片仅作装饰，0 引导、0 CTA | 高价值流量浪费 |
| 6 | **底部商品区品牌词乱码** | "新景区单人票 ¥0.01 ¥0.01" 没强调、没倒计时、没紧迫感 | 转化漏斗顶端就漏掉 |
| 7 | **同质化 Tab** | "景区门票 / 当地特产 / 会员充值 / 领券中心" 字号粗细相同 | 主体路径不清晰 |
| 8 | **没有情感锚点** | 没有"今日节目""明星表演""限时特惠"等剧情化内容 | 用户没有探索欲 |
| 9 | **底部齿轮 FAB 突兀** | 右下角圆形设置按钮，打断浏览节奏 | 误触 + 视觉噪音 |
| 10 | **节日主题"硬贴"** | 国庆 / 端午横幅是后加上去的浮动元素，与主调割裂 | 一过节日就显得脏 |

## 二、优化方向（After）

> 设计方向：**Vintage Circus × Modern Editorial**（复古马戏团 + 现代编辑感）
>
> - 选这个方向的唯一理由：你这是**马戏团主题景区**，那品牌记忆点就要立在这。
> - 跳出"山水绿/天空蓝"的同质化景区配色。

### 1. 调色板

| Token | 值 | 用途 |
|-------|----|----|
| `--brand-wine` | `#7A1F2B` | 主色（深酒红），用于强调、CTA、Tab 高亮 |
| `--brand-cream` | `#F5EEDC` | 主背景（奶油色），比白温柔，比米色高级 |
| `--brand-gold` | `#B4843C` | 点缀色（金棕色），分隔线、徽章、价格符号 |
| `--brand-ink` | `#1C1411` | 文字主色（深墨黑，非纯黑） |
| `--brand-paper` | `#FFFCF5` | 卡片背景，比主背景亮一档 |

### 2. 字体

- **标题**：Playfair Display（衬线，编辑感、复古戏剧张力）
- **正文**：PingFang SC + Inter fallback
- **数字/价格**：Playfair Display italic，戏剧张力 × 价格心理

### 4. 具体改造点

1. **Hero 重做**：放弃纯图轮播，改成"文字 + 状态条 + CTA + 配图"沉浸式布局
2. **状态条前置**：营业时间用"营业中·今天 4 场"生命感表达，不再是冷冰冰"08:00-18:00"
3. **地址 / 电话**：做成"导航 / 拨打"两个明确的 CTA 按钮，不再是文本
4. **功能区分群**：从 14 个入口扁平成 **4 个分类 + 每类 2-3 个** 重点入口
5. **加剧情内容**：今日必看表演（用 venue 数据可拉），制造浏览-点击冲动
6. **限时商品倒计时**：明确"今日特惠·限时秒杀"，数字够大、倒计时够明显
7. **底部齿轮 FAB**：放到"我的"Tab 内，或右上角"︙"菜单，不再打扰
8. **节日主题**：作为"情境模态"整体切换，不再是浮动元素叠加

## 四、落地建议

技术上是 uni-app，所以预览用 HTML + SCSS 重写即可。
落地步骤：

1. 替换 `pages/index/home-content.vue` 的 template + style
2. 不动 script 逻辑（数据请求结构没变）
3. 设计 Token 加到 `styles/themes.js`
4. 真机测试时用 vh/vmin 替换 rpx 的关键尺寸
